# Stackkit Web Customizer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or execute the tasks directly with TDD. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a local Next.js customizer app that produces offline Stackkit recipe commands from shared registry data.

**Architecture:** Add a browser-safe core subpath for customizer logic, then build `apps/customizer` as a small Next app over that API. Keep the app offline and avoid duplicating resolver or recipe behavior in UI code.

**Tech Stack:** TypeScript, Next.js, React, Vitest, lucide-react, Stackkit core and registry packages.

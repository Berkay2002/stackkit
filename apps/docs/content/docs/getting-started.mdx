## Installation

Install Stackkit globally, or skip the install step entirely and run it directly with `npx`.

<Tabs items={['npm', 'pnpm', 'yarn', 'bun']}>
  <Tab value="npm">
    ```bash
    npm install -g @berkayorhan/stackkit
    ```
  </Tab>
  <Tab value="pnpm">
    ```bash
    pnpm add -g @berkayorhan/stackkit
    ```
  </Tab>
  <Tab value="yarn">
    ```bash
    yarn global add @berkayorhan/stackkit
    ```
  </Tab>
  <Tab value="bun">
    ```bash
    bun add -g @berkayorhan/stackkit
    ```
  </Tab>
</Tabs>

Or run it once without installing:

```bash
npx @berkayorhan/stackkit@latest create my-app --web next --api fastapi --db postgres --auth auth0
```

## Generate Your First Project

The `create` command accepts stack-axis flags to compose your monorepo. The following example creates a full-stack project with a Next.js web app, a FastAPI backend, Postgres, Auth0, ShadCN UI, Docker support, and Vercel deployment configuration:

```bash
stackkit create my-app \
  --web next \
  --api fastapi \
  --db postgres \
  --auth auth0 \
  --with shadcn,docker \
  --deploy vercel
```

Stackkit records every module choice in `.stackkit/project.json` so future commands can inspect, diff, and evolve the project without guessing what was originally generated.

Prefer a lighter React setup? Generate a Vite single-page app or a full-stack TanStack Start app instead of Next.js:

```bash
# React SPA with Vite.
stackkit create my-spa --web vite

# Full-stack React with TanStack Start.
stackkit create my-app --web tanstack
```

React frameworks include ShadCN UI by default. Add `--ui none` to skip ShadCN, or `--ui tailwind` to swap it for plain Tailwind CSS.

Stackkit delegates ShadCN setup to the ShadCN CLI when that module is enabled. Clerk-backed Next.js stacks use the Clerk CLI as well, so official initializer behavior stays in the upstream tools instead of being copied into Stackkit templates.

Need an API-only container path? FastAPI can be paired with Docker and Kubernetes without selecting a web app:

```bash
stackkit create my-api --api fastapi --with docker --deploy k8s
```

<Callout title="Tip: skip AI skill installation for quick tests" type="info">
Pass `--skills skip --yes` to bypass the AI skill installation step and accept all prompts automatically — useful when you just want to see the generated output locally:

```bash
stackkit create my-app --web next --skills skip --yes
```
</Callout>

## Preview Without Writing Files

Stackkit supports dry-run previews so you can inspect the planned output before anything is written to disk.

**Preview a named preset**

```bash
stackkit create my-app --preset next-fastapi-postgres-auth0 --dry-run
```

**Preview an explicit stack**

```bash
stackkit create my-app --web next --api fastapi --db postgres --auth auth0 --dry-run
```

```bash
stackkit create my-app --preset next-postgres-clerk --dry-run
```

Dry-run output includes extractable `STACKKIT_PLAN_JSON_START` and `STACKKIT_PLAN_JSON_END` markers.

**Inspect a single planned file**

```bash
stackkit create my-app --web next --dry-run --view apps/web/package.json
```

## Validate the Generated Project

After generation, run the following sequence inside the project directory to confirm everything is wired up correctly:

```bash
cd my-app
pnpm install --lockfile-only
pnpm install --ignore-scripts
pnpm test
pnpm typecheck
pnpm build
pnpm lint
stackkit doctor
```

`stackkit doctor` checks every managed file in the project against its canonical template and reports any drift or missing entries.
